#### 🌐 [Antigravity Browser Bridge (v2.1.0 Enterprise)](https://github.com/FranciscoGrandon/antigravity-browser-bridge)
> **Motor Autónomo Chromium & Puente MCP de 40 Herramientas para Navegación Desatendida con Control WAI-ARIA**
* **Problema:** La automatización tradicional mediante WebDrivers o scripts invasivos de JavaScript es frágil ante cambios del DOM, satura el contexto volcando HTML crudo o capturas de pantalla pesadas, no penetra Shadow DOM ni IFrames anidados, y expone credenciales en texto plano.
* **Solución Técnica:** Ecosistema empresarial de automatización desatendida para Chromium (Microsoft Edge y Google Chrome MV3) acoplado a agentes LLM vía **Model Context Protocol (MCP 2.x)**:
  * **Poda Semántica WAI-ARIA Inteligente:** Genera un árbol accesible podado (`ref_N`) con selectores de sub-árbol (`root_selector`), viewport dinámico y ofuscación de datos sensibles, logrando una reducción de entre 40% y 60% en consumo de tokens.
  * **Perforación Profunda & Eventos CDP:** Navegación e indexación recursiva sobre `shadowRoot` abiertos e `<iframe same-origin>` con compensación geométrica de coordenadas acumuladas para clics exactos, simulación de hover, drag & drop continuo, selección semántica en comboboxes y exportación de PDFs vectoriales (`Page.printToPDF`).
  * **Catálogo de 40 Herramientas MCP Nativas:** Navegación avanzada, inspección DOM, almacenamiento web (`localStorage`/`sessionStorage`), manipulación de cookies vía CDP, control de descargas (`browser_download_wait`), gestión no bloqueante de diálogos (`alert`/`confirm`/`prompt`), ejecución en batch y recolección de métricas de rendimiento (`Performance.getMetrics`).
  * **Resiliencia & Ciberseguridad Robusta:** Detección de inactividad de red (`wait_network_idle`), WebSocket Hub local (`:8766`) con token secreto en **Windows Keyring**, respaldo de sesiones cifrado simétricamente (HMAC-SHA256 + keystream XOR) y cumplimiento normativo corporativo **100/100** acreditado con certificado SHA-256 (`CERT-ESSBIO-20261007-8DAD9D`).
* **Impacto:** Suite de pruebas con 100% de aprobación (8/8 suites), automatización desatendida de plataformas complejas (portales corporativos y SPAs en Angular Material / Ivy) con cero fallas de layout y máxima eficiencia de contexto.
* **Stack:** `Chromium Manifest V3 (Edge/Chrome)` `Chrome DevTools Protocol (CDP 1.3)` `WAI-ARIA Engine` `Model Context Protocol (MCP 2.x - 40 Tools)` `Python 3.12 (Asyncio WebSockets)` `Windows Keyring / HMAC-SHA256`

#### 🛡️ [ag_ops — CLI Engine for Agent Governance](https://github.com/FranciscoGrandon/ag-ops)
> **Arnés Determinista de Gobernanza, Guardarraíles Merkle, Runlevels Léxicos & AST Linting para Agentes Autónomos**
* **Problema:** Los agentes de IA autónomos son propensos a modificar o sabotear sus propios tests unitarios para forzar pases falsos, saturar la ventana de contexto inyectando miles de líneas de logs crudos, perder el estado de avance ante compactaciones bruscas (*200k-token lobotomy*) y violar restricciones estructurales de código.
* **Solución Técnica:** Motor CLI ultra-rápido y 100% determinista escrito en Python puro (librería estándar, sin dependencias externas) que actúa como puente físico de control de integridad entre el agente y el sistema operativo. Estructurado en 5 módulos desacoplados:
  * **`guard` (Merkle Tree & Lock):** Sella criptográficamente (SHA-256) el directorio de pruebas y certifica la fase inicial de fallo (`witness-red`), bloqueando y abortando con código 2 (`EACCES_TEST_TAMPERING`) si el agente intenta sabotear o alterar los tests al buscar el pase (`verify-green`).
  * **`distill` (Aislamiento de Procesos & Filtro Regex):** Ejecuta compilaciones y suites con timeout, aislando grupos de subprocesos y reduciendo logs masivos únicamente al delta crítico estructurado.
  * **`state` (Runlevels Lexicográficos 00..99):** Persistencia de fases y sellado Merkle de artefactos generados en disco (`.ag_state/NN_<slug>.json`), brindando inmunidad contra pérdidas de memoria en sesiones largas.
  * **`ast-lint` (Linter Estático AST <15ms):** Análisis sintáctico estático ultra-rápido del árbol AST para verificar reglas de diseño, autoría requerida y generar grafos de llamadas en Graphviz DOT.
  * **`regret-mine` (Minería Forense Git):** Análisis de regresiones y fallos históricos inspeccionando git diff y blame.
* **Impacto:** Suite de pruebas con 100% de aprobación (6/6 tests passed), garantía matemática de no-sabotaje de tests en agentes y economía de contexto garantizada.
* **Stack:** `Python 3.12 (Standard Library)` `ast Engine` `hashlib (Merkle Trees)` `subprocess Isolation` `Graphviz DOT` `JSON / CLI Architecture`

Almacena más de 2.2 GB de datos consolidados en formato columnar comprimido en **Snappy** con esquema unificado y tipado estricto de **33 columnas** (30 atributos de negocio + 3 de partición).
