## 🚀 Proyectos Destacados & Soluciones de Ingeniería

A continuación se destacan soluciones clave desarrolladas para la operación de servicios comerciales, analítica avanzada e Inteligencia Artificial:

### 🔬 [SGL Vision Studio & Lab](https://github.com/FranciscoGrandon/sgl-vision-studio)
> **Ecosistema On-Device & Desktop para Visión Artificial en Terreno**
- **Descripción:** Suite completa de entrenamiento, re-etiquetado activo (*Active Learning*) y banco de pruebas móvil en Android ([sgl-vision-lab](https://github.com/FranciscoGrandon/sgl-vision-lab)) con modelos TensorFlow Lite (`Float32`, $224 \times 224 \times 3$) para validar lecturas e imágenes de medidores en terreno.
- **Tecnologías:** `Python` `TensorFlow` `TFLite` `Android SDK` `Java` `OpenCV`

### 💡 [LECTRON & LECTRON APK](https://github.com/FranciscoGrandon/lectron-apk)
> **Lectura Inteligente de Medidores de Agua basada en IA Multimodal & Android Nativo**
- **Descripción:** Ecosistema compuesto por aplicación web de alto rendimiento y aplicación Android nativa para la interpretación automática de diales y rodillos analógicos de agua utilizando modelos multimodales Gemini con discriminación de $m^3$ vs. litros y almacenamiento en SQLite.
- **Tecnologías:** `Python` `FastAPI` `Gemini Vision API` `Android Native` `SQLite`

### 🛡️ [Validador PRO v2 & SigLIP](https://github.com/FranciscoGrandon/proyectos)
> **Auditoría y Clasificación Automatizada de Calidad Fotográfica**
- **Descripción:** Motor de clasificación visual y detección de anomalías fotográficas (fotos negras, desenfoque laplaciano, baja resolución, reflejos) con versión Android nativa (MobileNetV3) e inferencia Zero-Shot con Google SigLIP.
- **Tecnologías:** `PyTorch` `SigLIP` `MobileNetV3` `Android Native` `Tkinter GUI`

### 🛰️ [MockGPSPro](https://github.com/FranciscoGrandon/MockGPSPro)
> **Simulador de Telemetría GPS Anti-Heurística con Visor OpenStreetMap en Vivo**
- **Descripción:** Aplicación Android orientada a la simulación y testing avanzado de rutas GPS en terreno con bypass de restricciones heurísticas y visualización interactiva de mapas en vivo basada en OpenStreetMap.
- **Tecnologías:** `Android SDK` `Java` `OpenStreetMap` `GPS Telemetry` `Anti-Heuristic`

### 📱 [Registro de Entrega Essbio](https://github.com/FranciscoGrandon/registro-de-entrega-essbio)
> **Captura Georreferenciada en Terreno & Visor Cloudflare D1**
- **Descripción:** Plataforma móvil Android con cámara integrada y geolocalización de alta precisión (CameraGPS) conectada con sincronización cloud a una base de datos distribuida en Cloudflare D1 y visor web para auditoría de entregas.
- **Tecnologías:** `Android SDK` `CameraGPS` `Cloudflare D1` `Web Viewer` `SQLite`

### 🤖 [Agent Gateway & Antigravity Multiagent Orchestration](https://github.com/FranciscoGrandon/antigravity-multiagent-orchestration)
> **Pasarela Asíncrona Multi-Agente & Automatización Telegram**
- **Descripción:** Implementación del protocolo de orquestación y descomposición multiagente (`orchestration.md v2.0`) y pasarela en Python ([agent-gateway](https://github.com/FranciscoGrandon/agent-gateway)) que expone capacidades del CLI local hacia clientes remotos de Telegram con sandbox estricto.
- **Tecnologías:** `Python` `Antigravity CLI` `Telegram Bot API` `Multi-Agent Protocols` `Process Sandbox`

### 🏢 [SAP GUI Automation](https://github.com/FranciscoGrandon/sap-automation)
> **Automatización Desatendida en SAP GUI ERP-ISU con Python**
- **Descripción:** Automatización robótica de procesos (RPA) para SAP GUI for Windows (64-bit) en el mandante ERP-ISU Productivo (Essbio / Nuevosur), ejecutando transacciones críticas (`IW39`, `ZDM_0050`), extracción ALV y reportes masivos bajo estricta política de sólo lectura.
- **Tecnologías:** `Python` `SAP GUI Scripting` `Win32 COM` `Pandas`

### 📦 [Trazabilidad Postal Certificada](https://github.com/FranciscoGrandon/trazabilidad)
> **Monitoreo Automatizado End-to-End con API & Cruce Masivo**
- **Descripción:** Plataforma de control de despacho postal certificado que audita el 100% de los documentos entre SAP, imprenta AMF y Correos de Chile, combinando base de datos offline y sincronización en tiempo real vía API REST/SOAP.
- **Tecnologías:** `Python` `REST/SOAP API` `SAP Export` `Pandas` `Dashboard HTML`

### 🗄️ [Biblioteca Maestra SQL SAP HANA](https://github.com/FranciscoGrandon/proyectos)
> **Catálogo Indexado de 228 Scripts SQL Comerciales y Módulo Python**
- **Descripción:** Repositorio estructurado y paquete CLI en Python (`QueryLibrary`) que indexa y parametriza consultas analíticas críticas para facturación, medición, cortes e inspecciones sobre SAP HANA.
- **Tecnologías:** `Python CLI` `SAP HANA SQL` `Metadata Engine`
